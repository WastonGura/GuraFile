# GuraFile

GuraFile 是一个 Windows 优先的标签式文件管理器。它保留真实文件系统作为唯一文件来源，在本地建立索引，让你用标签而不是文件夹层级整理和查找文件。

## v0.5.0 日用稳定性 Beta

本版为日用稳定性 Beta 版本，在图谱预览与稳定文件操作基础上，全方位加固数据安全、故障自愈与日常大规模检索性能：

- **用户标签自动滚动备份（#71）**：标签结构变更或打标操作后自动生成 `tags_backup_yyyy-MM-dd.json`，每日最多一份，默认滚动保留最近 14 份有效快照，支持损坏检测与单事务安全还原；
- **历史数据库向前迁移矩阵（#72）**：支持从 v1（v0.1.0）至 v10（v0.5.0）的全自动化单事务逐级向前迁移，外键与 WAL 校验，保障升级过程历史用户数据完整无损；
- **数据库损坏检测与安全重建（#73）**：自动检测数据库完整性，对损坏数据库提供安全隔离（`.corrupt_timestamp.bak`）、重新扫描真实文件重建索引并从有效滚动备份自动恢复用户标签；
- **本地诊断日志与脱敏导出（#74）**：分级记录关键操作与异常日志（单文件 10 MB 自动轮转），提供一键导出脱敏诊断包 ZIP 功能；
- **介质能力与降级状态提示（#75）**：智能识别 NTFS、可移动盘（FAT32/exFAT）、网络共享（UNC/SMB）与只读卷，对降级状态提供清晰的状态栏提示与安全保护；
- **扫描与写操作崩溃恢复（#76, #77）**：持久化扫描会话与文件操作意图；非正常退出或崩溃重启后自动补偿对账扫描，核对磁盘状态并更新索引，绝不盲目重放物理写操作；
- **十万文件索引与冷启动优化（#78）**：Schema v8 为文件名建立专用前缀索引，消除 Temp B-Tree 排序，10 万文件冷启动查询约 1.0 秒、扫描吞吐达 4,000+ files/s；
- **FTS5 全文搜索与千文件批量标签（#79）**：引入 SQLite FTS5 全文检索表 `files_fts` 与同步触发器，提供毫秒级搜索；千文件批量打标耗时收敛至 10 ms 级；
- **已保存筛选视图（#80）**：支持保存搜索词、排序与标签组合；关联标签被删时视图自动标记 `[失效]` 并采用 `0 = 1` 边界保护防无谓扩散；
- **无障碍、焦点管理与最小设置页（#81）**：实现轻量设置持久化、主窗口完整 TabIndex 键盘导航编排、`LiveSetting.Polite` 状态播报与剪贴板并发防冲突；
- **离线图谱预览与 Windows STA 安全文件操作保留**：保留 Cytoscape.js 3.30.2 本地二部图可视化（300 节点性能保护）与 Windows `IFileOperation` 安全软删除（`FOFX_RECYCLEONDELETE` + `FOF_ALLOWUNDO`）。

## 安装与运行

1. 从 GitHub Releases 下载 `GuraFile-v0.5.0-win-x64.zip` 和对应的 `.sha256` 文件。
2. 校验压缩包 SHA-256 后解压到可写目录。
3. 运行 `GuraFile.exe`。应用为未签名预览包，Windows 可能显示 SmartScreen 提示。

系统要求：x64 Windows 10 版本 1809（build 17763）或更高版本。发布包为 unpackaged、自包含部署，不要求单独安装 .NET 或 Windows App Runtime。

## 基本使用

1. 在左侧添加管理根目录；应用会立即在后台建立索引，必要时也可选择“扫描”。
2. 在中间文件列表选择一个或多个文件。
3. 在左侧创建并选择标签，然后选择“贴到文件”。
4. 开启“按所选标签筛选”，选择“满足任一标签”或“满足全部标签”。
5. 在搜索框中输入关键词，基于 FTS5 引擎毫秒级实时筛选文件名与路径。
6. 可将常用筛选条件保存为“已保存视图”，在左侧视图列表快速切换。
7. 在工具栏切换“列表”与“图谱”视图；在图谱中可拖拽、缩放、框选文件节点批量打标，或双击安全打开。
8. 在工具栏或快捷键执行“复制”、“剪切”、“粘贴到…”、“移动到…”、“重命名”或“删除”。
9. 在右侧结构化面板查看属性、在线状态、稳定身份状态与标签，使用“打开”、“在资源管理器中显示”或“复制路径”。
10. 进入“设置”页面调整常规偏好，或点击“导出诊断包...”导出脱敏运行日志与系统诊断包。
11. 使用“导出备份”保存用户标签；也可通过“历史备份...”浏览本机自动滚动快照并执行恢复。

## 数据位置与安全

- **数据库索引文件**：`%LOCALAPPDATA%\GuraFile\index.db`。移除管理根目录只会删除 GuraFile 索引，绝不删除真实文件。
- **用户标签自动滚动备份**：`%LOCALAPPDATA%\GuraFile\backups\tags\tags_backup_yyyy-MM-dd.json`。
- **诊断日志存储目录**：`%LOCALAPPDATA%\GuraFile\logs\`。
- **用户偏好设置文件**：`%LOCALAPPDATA%\GuraFile\settings.json`。
- **数据安全边界**：真实文件系统是文件的唯一权威来源。SQLite 数据库仅保存可随时重建的文件索引、用户标签及视图元数据。

## 备份与恢复

- **自动滚动备份位置**：默认保存在 `%LOCALAPPDATA%\GuraFile\backups\tags\`，文件名格式为 `tags_backup_yyyy-MM-dd.json`。
- **触发与保留规则**：在用户标签创建、重命名、删除，以及文件添加/移除用户标签后自动触发；同一自然日最多保留一份有效快照且无变化不重复写入；默认滚动保留最近 14 份日快照并自动清理最旧备份；备份写入失败完全不阻断核心标签操作。
- **恢复步骤**：
  1. 在主界面左侧点击“历史备份...”打开备份列表；
  2. 列表将展示每个快照的文件名、大小与校验状态（自动检测并标识损坏备份，防止异常崩溃）；
  3. 选中所需有效快照后点击“恢复所选备份”（也可随时点击“导入备份”选择任意 JSON 文件）；
  4. 系统通过单事务完整校验并恢复用户标签与关系，呈现冲突与未匹配报告，且自动标签与真实文件完好不受破坏。
- **数据库损坏自愈重建**：若索引数据库遭遇意外损坏，系统将提供安全恢复引导：原损坏数据库安全隔离至 `.corrupt_timestamp.bak`，随后自动重建新数据库、重扫管理根目录并从最新有效滚动备份还原用户标签。
- JSON 备份格式为 `GuraFile.UserTags` v1，严格仅包含用户标签和用户关系；自动标签、SQLite 数据库文件及真实文件绝不进入备份。
- stable 身份只按稳定文件身份恢复；path 降级记录只匹配在线 path 身份，不会把标签猜测绑定到同路径替换文件。
- 原生兼容历史版本数据库（Schema v1 ~ v10）；升级前建议先导出标签备份。
- 单个 JSON 备份上限为 64 MB；超限时导出会明确失败，不会生成无法重新导入的文件。

## 诊断导出

- 应用内置轻量脱敏诊断导出功能，用户可在“设置”页面点击“导出诊断包...”。
- 导出的 ZIP 压缩包包含本地运行日志、数据库完整性状态以及已脱敏的管理根目录配置。
- 诊断数据严格剔除用户名、机密标识等敏感信息，不包含任何真实文件内容。

## 已知限制

- 实时监听基于 FileSystemWatcher，正常负载目标为 2 秒内更新，并由启动、错误和离线恢复扫描兜底；本版不使用 NTFS USN Journal。
- 删除操作仅支持删除到 Windows 回收站，不提供永久删除选项；若回收站不可用则拒绝删除。
- 图谱预览功能设定 300 个文件节点上限以确保交互流畅；超过 300 个文件时图谱会提示收窄筛选条件，不截断渲染。
- 尚未提供跨平台版本。
- 当前仅提供未签名的 Windows x64 便携压缩包。

## 隐私与数据边界

GuraFile 的索引和标签保存在本机，不上传文件内容。真实文件始终位于原目录；当前版本只会读取元数据和最多 32 字节文件头、打开文件、请求资源管理器定位，以及修改本地索引和用户选择的 JSON 备份。

## 开发与验证

需要 .NET SDK 10.0.400 或更高版本。在仓库根目录使用 PowerShell 7：

```powershell
dotnet restore .\GuraFile.slnx
dotnet build .\GuraFile.slnx --configuration Release --no-restore
dotnet test .\tests\GuraFile.Tests\GuraFile.Tests.csproj --configuration Release --no-build
.\tests\LaunchSmoke.ps1 -Configuration Release -RuntimeIdentifier win-x64
```

生成可发布包：

```powershell
.\scripts\PackageRelease.ps1 -Version 0.5.0
```
