# v0.2.0 发布验收

验收日期：2026-09-01
目标平台：Windows 10 1809 及以上，x64

## 功能与数据

- [x] 临时目录完成“扫描 → 自动分类 → 用户贴标 → 外部创建/改名/改扩展名/移动/删除 → 重启恢复”全链路测试。
- [x] 正常负载的外部变化在 2 秒内进入索引，自动格式标签随扩展名变化，用户标签保持不变。
- [x] 扩展名与文件头冲突显示“类型冲突”；文件头读取失败、占用文件和无权限项不会阻断索引队列。
- [x] 模拟监听溢出或主动丢失事件后，全根差异扫描使数据库与磁盘重新一致。
- [x] 根目录离线时节点和标签不被删除；重新上线后自动重扫并恢复监听。
- [x] 恢复扫描期间继续监听，重复恢复请求合并，Unwatch 与旧 watcher 回调不会重新登记已移除根目录。
- [x] 本版不读取 NTFS USN Journal。
